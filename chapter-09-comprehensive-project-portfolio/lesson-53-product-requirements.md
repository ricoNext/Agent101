# 第 1 课：写一页产品需求

> 所属章节：[第 9 章：完成一个可展示的全栈 Agent 产品](./index.md)  
> 下一课：[第 2 课：冻结架构和核心任务](./lesson-54-architecture-core-tasks.md)

创建 `docs/product-requirements.md`，必须回答：

- 谁在使用；
- 现有流程有什么问题；
- Agent 自动做哪几步；
- 人类必须做哪几步；
- 失败时如何处理；
- 成功指标是什么；
- 哪些数据和工具不允许访问；
- 第一版明确不做什么。

示例目标：

```text
用户：维护 Python 服务的后端工程师。
目标：在隔离仓库中定位失败测试并生成可审查的修复建议。
自动化：搜索、读取、生成测试、运行固定测试命令、生成 diff。
人工：批准应用 diff、发起 PR、合并代码。
成功：20 个 Golden Tasks 中至少 15 个完成，引用准确率 >= 90%，高风险写操作 100% 审批。
不做：任意 Shell、直接推送生产分支、自动合并 PR。
```
