# 第 6 课：运维治理台和本章验收

> 所属章节：[第 7 章：生产工程、可观测性与 FinOps](./README.md)  
> 上一课：[第 5 课：版本、灰度和回滚](./第05课-版本、灰度和回滚.md)

创建 `/operations` 页面，包含：

- 服务健康和版本；
- 成功率、P95、成本趋势；
- 按租户/任务/模型归因；
- Trace 搜索和模拟 Replay；
- 预算超限事件；
- 灰度比例、候选版本和回滚操作；
- 告警列表。

本章最终验收：

- Docker Compose 在干净环境启动；
- `live` 与 `ready` 健康检查不同；
- 所有 Run 可追踪到 Trace 和版本；
- 预算超限不会静默继续；
- 可生成成本报表；
- 完成一次灰度失败和回滚演练；
- 写出 `docs/runbook.md`，包括启动、排错、回滚和紧急停止。
