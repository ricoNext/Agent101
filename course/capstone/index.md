# 综合项目与作品集

七个里程碑最终合并为同一套 Agent Engineering Platform。综合项目不再建设另一套底层设施，而是选择真实业务方向证明平台能力。

## 综合项目二选一

### 方向 A：企业级深度研究平台

- 多源数据与内部知识接入
- 研究任务拆解与多 Agent 协作
- 事实核验、引用追溯与可信度评估
- 报告生成、Eval、Trace 与成本统计

### 方向 B：软件工程 Agent / 软件工厂

- 需求分析、任务拆解与代码修改
- 多角色 Agent 的职责和权限边界
- Git、代码审查、测试与 CI 集成
- Sandbox 隔离、质量门禁与失败恢复

## 四类作品成果

1. Agent Foundation Platform
2. Codebase Agent
3. Agent Eval & Operations Console
4. 二选一综合业务项目

最终答辩统一展示架构、运行证据、评测改进、安全边界、成本设计、已知限制与部署说明。
