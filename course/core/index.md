# 核心课程

七章核心课程按能力依赖顺序学习，每章交付一个可验收的项目里程碑，共同演进为同一套 Agent Engineering Platform。

| 章节 | 主题 | 项目里程碑 |
| --- | --- | --- |
| [第一章](./chapter-01-llm-gateway/) | LLM API、Prompt、Structured Output 与 Gateway | M1：LLM Gateway |
| [第二章](./chapter-02-tool-runtime-mcp/) | Function Calling、Tool Runtime 与 MCP | M2：Agent Tool Runtime |
| [第三章](./chapter-03-agent-loop-codebase-agent/) | Agent Loop、State、Harness 与 Codebase Agent | M3：Codebase Agent |
| [第四章](./chapter-04-context-memory-codebase-rag/) | Context Engineering、Memory 与 Codebase RAG | M4：Context & RAG |
| [第五章](./chapter-05-multi-agent-skills/) | Multi-Agent、Subagent 与 Skill | M5：Agent Collaboration |
| [第六章](./chapter-06-agent-eval/) | Agent Eval 工程 | M6：Agent Eval Platform |
| [第七章](./chapter-07-production-governance/) | 生产工程、FinOps、安全治理与部署 | M7：Production Ready |

建议从第一章开始按序推进；Eval、安全与治理从第一章起逐步加入平台，而不是最后才补。
