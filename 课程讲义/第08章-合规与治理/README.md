# 第 8 章：身份、审批、审计与治理

## 本章完成后的效果

完成本章后，平台不再把“用户传来的 header”当成授权依据，而是具备最小的身份、Scope、审批、审计、脱敏、租户隔离和 Kill Switch 设计。

法规名称和生效时间会变化；本章教学的是如何把风险要求翻译成可以实现和验证的工程控制。
