# 第 9 章：完成一个可展示的全栈 Agent 产品

## 本章完成后的效果

本章不再增加新的基础设施。你要从已经实现的能力中选择一个真实场景，冻结范围、交付产品、做评测、部署、演示和答辩。

选择一个方向：

1. 企业级深度研究平台；
2. 新一代软件工厂；
3. 企业知识与流程工作台。

只选一个。作品集的可信度来自一条可靠主流程，而不是十个未完成入口。
